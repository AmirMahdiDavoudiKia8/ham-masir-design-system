# Motion

Ham-Masir motion is patient and accompanying — gentle color/transform
transitions, never bounce or spring. Components reference these durations
through Tailwind (`duration-micro`, `duration-standard`, `duration-entrance`,
`duration-sheet`) with the shared easing curve.
