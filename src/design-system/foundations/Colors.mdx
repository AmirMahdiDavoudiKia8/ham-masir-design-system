# Colors

Six hero colors — the whole Ham-Masir world. Swatches read from `lib/tokens.ts` (typed mirror of `tokens.css`), so docs and code never drift.

      />

              : c.name === "warning"
                ? "bg-alert-soft · text-alert · border-alert"
                : c.name === "danger"
                  ? "text-danger · border-danger"
                  : `bg-${c.name} · text-${c.name}-foreground`}
        </code>
      </div>
    </div>
  ))}
</div>
