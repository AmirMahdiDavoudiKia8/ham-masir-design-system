### Radius System

مقیاس Radius هم‌مسیر شامل مقادیر پایه‌ی Primitive و نام‌های معنایی‌ای است که کامپوننت‌های واقعی محصول از آن‌ها استفاده می‌کنند.

در استفاده از Radius، تا جای ممکن از نام‌های Semantic استفاده کن؛ برای مثال:

- `rounded-card`
- `rounded-chip`

این کار باعث می‌شود اگر در آینده شکل یا میزان گردی یک نوع کامپوننت تغییر کرد، تغییر فقط در یک Token انجام شود و به‌صورت یکپارچه در تمام نقاطی که از آن استفاده می‌کنند اعمال شود.

مقادیر Primitive و Semantic Aliasها باید دقیقاً با مقادیر تعریف‌شده در `tokens.css` هماهنگ باشند و هیچ مقدار Radius مستقلی خارج از Token System تعریف نشود.
