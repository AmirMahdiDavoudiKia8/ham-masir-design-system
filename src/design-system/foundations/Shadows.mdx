# Shadows

Elevation plus semantic shadows. Resting surfaces stay quiet (border and
surface carry hierarchy); shadows mark lift — hover, dropdowns, dialogs,
sheets, toasts. Values mirror `tokens.css`.

<div dir="ltr" style={{ display: "flex", flexWrap: "wrap", gap: 16, marginTop: 16 }}>

      <span
        aria-hidden
        style={{ width: 120, height: 72, background: "var(--color-surface)", borderRadius: 12 }}
        className={cls}
      />
      <code style={{ fontSize: 12 }}>{name}</code>
      <code style={{ fontSize: 11, color: "var(--color-muted-foreground)" }}>{cls}</code>
    </div>
  ))}
