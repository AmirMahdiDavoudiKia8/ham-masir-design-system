### Shadows

Elevation در هم‌مسیر باید آرام و هدفمند باشد. سطوح در حالت عادی بیشتر با Border و رنگ Surface سلسله‌مراتب می‌گیرند و Shadow فقط برای نشان‌دادن بالا آمدن، انتخاب‌شدن یا شناور بودن استفاده می‌شود. `none` برای سطح‌های عادی Grid، `card` برای Cardها و Hover روی Mentor Tile، `brand` برای Glow اصلی و حالت‌های Primary/Selected، و `lifted` برای عناصر شناور مثل Bottom Sheet، Toast، Side Menu، Support Button و Suggestion Dropdown است. `floating` برای Hover روی Theme Toggle و `dropdown` برای Hover روی Strip Card استفاده می‌شود. `popover`، `dialog` و `sheet` تعریف شده‌اند اما فعلاً استفاده نمی‌شوند. مقادیر باید با `tokens.css` هماهنگ باشند.
