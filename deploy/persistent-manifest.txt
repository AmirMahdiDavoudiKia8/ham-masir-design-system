# Single source of truth for everything the app writes at runtime.
#
# Both deploy/link-persistent.sh (applies the symlinks on the VPS) and
# scripts/check-persistent-coverage.mjs (fails the build if the code writes
# somewhere this file doesn't cover) read this. Adding a runtime-written path
# to the code without adding it here now fails locally before you can ship it,
# instead of silently resetting that data on the next release.
#
# Format:  kind | path inside the release | name under persistent/
#   dir    the release path is a directory; replaced with `rm -rf` + `ln -s`
#   file   the release path is a file;      replaced with `rm -f`  + `ln -s`
#   read   the code reads this path but never writes it — no symlink needed.
#          The third column is the reason, so a future reader can re-check it.

dir  | src/data/mentorPortal          | mentorPortal
dir  | src/data/analytics             | analytics
dir  | public/mentors/portal          | mentors-uploads

file | src/data/paymentRequests.json  | paymentRequests.json
file | src/data/studentBookings.json  | studentBookings.json
file | src/data/studentIdentities.json| studentIdentities.json
file | src/data/studentProfiles.json  | studentProfiles.json
file | src/data/leads.json            | leads.json
file | src/data/mentors/mentors.json  | mentors-catalogue.json
file | src/data/progress/progress.json| progress.json
file | src/data/pushSubscriptions.json| pushSubscriptions.json
file | .env.local                     | .env.local

read | src/data/mentors               | directory is only enumerated for catalogue JSON; the one writable file in it (mentors.json) is linked above
